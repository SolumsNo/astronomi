# Christian Solum — Astrofotografi

Statisk porteføljeside laget for GitHub Pages.

## Lokal visning
Åpne `index.html` i en nettleser.

## GitHub Pages
1. Lag et nytt GitHub-repository, for eksempel `astrofoto`.
2. Last opp hele innholdet i denne mappen til repository-roten.
3. Gå til **Settings → Pages**.
4. Velg **Deploy from a branch**.
5. Velg `main` og `/ (root)`, og trykk **Save**.
6. Etter kort tid får siden en adresse som `https://brukernavn.github.io/astrofoto/`.

## Endre bilder og tekster
Bildeinformasjon ligger i `script.js`. Bildene ligger i `assets/images/`.
